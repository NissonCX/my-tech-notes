# 2026 年 10 月：给 macOS(Apple Silicon) 上的 Ollama 配图形界面

## 核心结论

1. **官方 Ollama.app 没有对话窗口**——它是「服务管理 + 设置 + 把模型接进别的 App」，别指望它当聊天界面。
2. **最省事**：装原生桌面客户端（Cherry Studio / Chatbox），直连 `localhost:11434`，零 Docker、中文原生、不吃额外内存大头。
3. **最强大**：Open WebUI（Docker，用 `:slim` 镜像）；但 macOS 容器拿不到 Metal，**Ollama 必须留在宿主机**。

### 关键细节

- **Ollama.app**：cask token 其实是 `ollama-app`（`brew install --cask ollama` 会被解析过去），版本 0.35.1、要求 macOS ≥ 14、Electron 应用、自动更新。界面只有 **Apps**（把模型接进 Claude Desktop / ChatGPT Desktop）和 **Settings**（含上下文长度滑杆）。官方文档全文（`llms-full.txt`，7284 行）**没有任何应用内聊天窗的描述**；文档里所有「聊天」路径都指向第三方 App 或 API。
  - ⚠️ cask 会同时往 `$HOMEBREW_PREFIX/bin/ollama` 放一个 CLI，与你 formula 的 `/opt/homebrew/bin/ollama` **同路径**，二者别并存。
  - 裸 `ollama` 命令 + `ollama launch` 是终端 TUI/启动器，不是 GUI。
- **Cherry Studio**：免费开源 AGPL-3.0，`v2.1.4` 提供 `Cherry-Studio-2.1.4-mac-arm64.dmg`；源码 `packages/provider-registry/src/providers/ollama.ts` 内置 Ollama；界面语言含 `zh-cn.json`。文档站本身是中文的。
- **Chatbox**：免费（另有订阅），社区版 GPL-3.0；`src/shared/providers/definitions/ollama.ts` + `zh-Hans` 界面。
- **ChatWise**：`26.4.0`；免费档 $0（个人非商用），Pro 一次性 **$29**（标价 $49）。
- **Msty**：Studio 免费 $0，明确含 Ollama / Llama.cpp / MLX 本地引擎；Aurum **$149/年** 或 **$349** 买断。
- **LM Studio**：**不是 Ollama 客户端**——自带 llama.cpp(GGUF)+MLX 运行时、自己的模型下载源和 OpenAI 兼容服务端，是 Ollama 的**替代品**。
- **Open WebUI**：官方推荐 Docker，命令含 `--add-host=host.docker.internal:host-gateway`（让容器访问宿主机 Ollama）；`:main` 镜像 **1.66GB**、`:slim` **176MB**（官方 2026-09-28 在 linux/amd64 实测）。**没有原生桌面二进制**，「Desktop」指的是浏览器 PWA 安装。许可证是自定义的 Open WebUI License（非 OSI 标准），另有企业版。
- **LibreChat**：需 Git + `docker compose`，端口 3080。**Apple Silicon 专属坑**：默认 MongoDB 镜像需要 AVX 指令，M 系列不支持会启动即崩，必须写 `docker-compose.override.yml` 换成 `mongo:4.4.18`。MIT。
- **LobeHub**：桌面版 `v2.2.18` 有 arm64 dmg，`locales/zh-CN` 与桌面端资源均含中文；许可证为 LobeHub Community License（Apache-2.0 + 附加条件）。
- **Page Assist**：Chrome / Firefox / Edge 三家商店都有；MIT；内置 Ollama、LM Studio、OpenAI 兼容三类 provider。

## 二、16GB 内存账（最关键）

- GUI 本身只是 **HTTP 客户端**，不加载模型权重——权重只活在 `ollama serve` 进程里。所以「GUI 抢内存」的说法基本不成立，**真正的风险是 Docker 的 Linux VM + 容器**。
- Ollama 上下文默认按显存分档：**< 24 GiB → 只有 4k**。16GB Mac 正落在这档，需要在 Settings 或 `OLLAMA_CONTEXT_LENGTH` 里手动调大，且**调大即涨内存**。
- `OLLAMA_MAX_LOADED_MODELS` 默认 3（CPU 推理），16GB 上建议设 **1**；`OLLAMA_NUM_PARALLEL` 默认 1，内存按 `NUM_PARALLEL × CONTEXT_LENGTH` 放大。
- Docker Desktop 的 GPU 支持文档**只覆盖 Windows**；macOS 容器跑在 Linux VM 里，**拿不到 Metal**——所以别用 Open WebUI 的 `:ollama` 镜像变体，Ollama 留在宿主机、容器连 `host.docker.internal:11434`。
- 不要同时常驻两个大模型（`qwen3.5:9b` + `gemma4:12b`），这条与 [[2026年10月-M4-16GB-Ollama小模型选型]] 一致。
- 各 GUI 进程的确切内存占用：**未找到公开资料**。

## 三、推荐（最省事 → 最强大）

1. **Cherry Studio**（最省事）：一行 dmg 装完，原生 arm64，中文界面，直连 `localhost:11434`，零 Docker、零配置冲突。取舍：多一个 Electron 应用常驻，功能多但也就意味着更重；模型仍在 ollama 进程里。
2. **Chatbox / ChatWise**（备选轻量）：Chatbox 更轻、免费；ChatWise 体验更精致但要 $29。取舍：ChatWise 免费档限个人非商用。
3. **Open WebUI + `:slim`**（最强大）：RAG、文档上传、联网、多用户、PWA 装进 Dock。取舍：必须常开 Docker Desktop（macOS 上 VM 自身要占内存），`:slim` 少了内置 embedding，做知识库需外接 embedding 提供方（可直接指回 ollama）；许可证非标准开源。

> 想要官方那只菜单栏图标 → `brew install --cask ollama`，但**先 `brew uninstall ollama`**，否则两个包抢同一个 `bin/ollama`。

## 常见误解

- ❌「官方 App 是个聊天客户端」→ 官方文档里它只有 Apps + Settings + 自动更新。
- ❌「LM Studio 是 Ollama 的图形界面」→ 它自带推理引擎和模型库，是替代品。
- ❌「Open WebUI 桌面版是个原生 App」→ 官方说的是浏览器 PWA 安装。
- ❌「GUI 会跟 Ollama 抢显存」→ 客户端不装权重；抢内存的是 Docker VM 和第二个模型。
