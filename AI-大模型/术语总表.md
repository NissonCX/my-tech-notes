# 术语总表（大模型推理）

中英对照。看图看论文、写文档、面试时用。

## 回答

### 核心结论

1. 口语概念和术语一一对应，用术语说话才显得专业。
2. **prefill / decode**、**prefix caching**、**KV cache 显存** 是三个最该刻进脑子的。
3. 术语按流程分组：输入 → 结构 → 推理 → 缓存与硬件。

### 怎么用

学会术语的标志是**能组句**。四句可以直接用在文档或面试里：

- "这次请求的 prompt 有 48K token，其中约 90% 命中了 **prefix cache**，实际只需要 **prefill** 新增的那 5K。"
- "**decode** 阶段是 **memory-bound** 的，瓶颈在 **KV cache 的显存带宽**，不在算力。"
- "我们把 **GQA** 的 KV 头数从 32 降到 8，**KV cache** 缩小到 1/4，**并发数**直接上去了。"
- "长 **prefill** 会阻塞同一个 batch 里的 **decode**，所以我们上了 **chunked prefill**，长期看要做 **PD 分离**。"
- "DeepSeek-V3 是 671B 总参数的 **MoE**，但每个 token 只激活约 37B；它的 FFN 计算量接近 37B 模型，容量却接近 671B 模型。"
- "**DSA** 用 **lightning indexer** 选 top-k，主注意力只算这 k 个 key；indexer 仍要给所有 key 打便宜分数。"

### 最该记的

| 概念 | 一句话 |
|---|---|
| **prefill / decode** | 一个算力受限，一个访存受限——**所有优化都在这个区分上** |
| **prefix caching** | "最长公共前缀"匹配，追加便宜、修改昂贵 |
| **KV cache 显存** | 层数 × 位置数 × K/V 维度 × 2 × 字节数 —— 并发数的天花板 |
| **MoE / DSA** | MoE 稀疏 FFN 专家，DSA 稀疏注意力连接——两者都在拆开“能力”和“成本” |
