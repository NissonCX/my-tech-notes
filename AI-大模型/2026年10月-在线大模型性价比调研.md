# 2026 年 10 月：在线大模型（API）性价比调研

> 抓取日期 **2026-10-04**（Asia/Shanghai）。所有价格与分数均来自当日真实抓取的页面，URL 见文末「来源」。
> 凡未从一手页面核实的，正文一律标注「未核实」。**模型价格变动极快，下单前请复核。**

## 问题

调查一下现在网上这些模型，哪些性价比最高？

## 回答

### 核心结论

1. **性价比要看「每美元智能」，不是单价**：按 Artificial Analysis（AA）智能指数与「每任务成本」算，旗舰档 **GPT-6.1 Sol**（智能 51.8、$0.72/任务）比同分数的 Claude Sonnet 5.5 / Fable 5.1 **便宜约 10 倍**；开源档 **小米 MiMo-V2.6-Pro**（46.3、$0.13/任务）与 **智谱 GLM-5.3-Flash**（41.8、$0.25/任务）是当前两张最划算的牌。
2. **中文/国内场景**：低价三强是 **DeepSeek-V4.1-Flash**（空闲 ¥1 / 缓存 ¥0.02 / 输出 ¥4）、**GLM-5.3-Flash**（¥0.8 / ¥0.23 / ¥2.8）、**MiniMax-M3**（¥2.1 / ¥0.42 / ¥8.4）；要接近前沿能力则 **Qwen3.8-Max**（¥12 / ¥36）或 **Kimi K3**（¥20 / ¥100）。
3. **最强的 ≠ 最值的**：Claude Opus 5.5 / Fable 5.1 是能力天花板，但每美元智能只有 GPT-6.1 Sol 的 **1/7 ~ 1/10**——预算有限时，它们是「最后一档 5% 难题」的选项，不该做默认模型。

### 一、先立口径：什么叫「性价比」

**单价（$/1M tokens）不等于实际成本。** 同一个任务的账单由四件事决定：

| 变量 | 影响 | 量级 |
|---|---|---|
| **缓存命中率** | 命中价 = 输入价的 **0.8%–25%**（小米 0.8%、DeepSeek 2%、Anthropic 2.5–10%、OpenAI 5–10%、Grok 25%） | Agent 场景省 80–95% |
| **输出 token 数** | 输出价普遍是输入的 5–10 倍，且**思考 token 按输出计费** | 差 2–5 倍 |
| **Verbose 程度** | 同样题目，啰嗦的模型多烧 3–6 倍 token | 见下方 Sonnet 5.5 例子 |
| **折扣** | Batch 5 折、DeepSeek 夜间 5 折、百炼海外错峰 4 折 | 省 20–50% |

本笔记用三个指标：

- **AA 智能指数 v4.3.2**：AA 用 10 项评测加权而成（Agents 30%、Coding 20%、科学推理 20%、通用 30%），是目前覆盖面最广的独立口径。
- **每任务成本（cost per task）**：AA 的原话是「按各评测权重，把 input / cached / output 三种 token 的实际消耗量乘对应单价再除以任务数」——**已经含了各模型自己的啰嗦程度和缓存折扣**，比单价更接近真实账单。
- **分/美元 = 智能指数 ÷ 每任务成本**（本笔记自算）：直观的「性价比」排名。

> AA 另有一个 **blended price** 口径，按 **缓存命中 : 未命中输入 : 输出 = 7 : 2 : 1** 加权——如果你要做粗略估算，用它比用「输入价」更接近现实（因为 Agent 场景大部分输入是缓存命中）。

> ⚠️ 口径陷阱：分/美元受「该模型在 AA 题目上啰嗦不啰嗦」影响。Claude Sonnet 5.5（max）智能 56 分但要 $7.67/任务，就是因为它跑了 4.2 亿输出 token（中位数约 8100 万）。

**但按「花费」排名会完全反过来**：近 30 天花费结构是 General 31.1% / Agent 30.5% / Code 28.5% / Data 10.0%，而 Agent 工作流里花费第一的是 **gpt-6-astra（16%）**。也就是说：**小众的贵模型吃掉大头的钱，海量的便宜模型吃掉大头的量**——这正是「性价比选型」能省钱的原因。

**真实 coding agent 单会话成本中位数**（USD；OpenRouter 口径，按 harness × 模型 × 会话长度分桶）：

| Harness + 模型 | 单轮 | 短会话 | 典型 | 长会话 |
|---|---|---|---|---|
| Claude Code + claude-5-fable | 0.289 | 1.049 | 4.527 | **26.192** |
| Codex + gpt-6-astra | 0.118 | 0.573 | 2.934 | 19.558 |
| Claude Code + claude-opus-5 | 0.194 | 0.389 | 1.767 | 10.585 |
| Kilo Code + kimi-k3 | 0.058 | 0.224 | 0.853 | 4.829 |
| Codex + gpt-6-sol | 0.023 | 0.107 | 0.596 | 3.022 |

同一模型从「单轮」到「长会话」放大 **50–91 倍**（Claude Code + claude-5-fable：0.289 → 26.192 = 91×）。**结论：做预算要按「会话」而不是按「token 单价」算**——否则会低估一到两个数量级。

### 七、降价手段清单（不改模型也能省 50–95%）

| 手段 | 省多少 | 适用 |
|---|---|---|
| **Prompt / 前缀缓存** | 命中价 = 输入价 0.8%–25%，真实部署命中率 70%～90%+ | 长 system prompt、Agent 多轮、RAG 固定片段 |
| **Batch API** | **5 折**（OpenAI/Anthropic/Gemini 三家文档均为 50%，国内百炼/智谱/小米同样） | 离线数据处理 |
| **错峰 / 夜间** | DeepSeek 半价；百炼海外 4 折 | 可延迟任务 |
| **Flex（OpenAI）/ 优先级取舍** | Flex 半价、Fast 2 倍、Ultrafast 6 倍 | 按 SLA 分层 |
| **思考预算** | 输出 token 降 30–70% | `reasoning_effort`、thinking budget 调低 |
| **模型路由** | 账单降 5–20 倍 | 小模型做分类/改写，大模型做兜底 |
| **Prompt 瘦身** | 10–40% | 砍 few-shot、压缩历史、结构化输出 |

## 常见误解

| 误解 | 纠正 |
|---|---|
| 「单价便宜就省钱」 | 单价 × token 量才是账单。Claude Sonnet 5.5 单价和 GPT-6.1 Sol 一样（$2/$10），但每任务贵 **10.6 倍**——同一套题它烧了 4.2 亿输出 token，是 Sol（6700 万）的 **6 倍多**。 |
| 「最强模型干活最好」 | Opus 5.5 只比 GPT-6.1 Sol 高 5.8 分，贵 8.3 倍。除非任务明确卡在那 5% 上，否则不划算。 |
| 「开源 = 免费」 | 开源只免授权费。自部署要算 GPU 小时、运维、量化损失；日均调用量低于某个阈值时，API 反而更便宜。 |
| 「缓存命中一定是 1 折」 | 各家不同且有的贵得离谱：小米 **0.8%**、DeepSeek **2%**、Anthropic 2.5–10%、OpenAI 5–10%、**Grok 25%**；缓存写入另算（OpenAI 1.25×、Anthropic 5min 1.25× / 1h 2×，DeepSeek 与智谱当前免费）；且百炼的缓存与 Batch **不能叠加**。 |
| 「榜单分差 = 能力分差」 | SWE-bench Verified 前 30 名做相邻配对 McNemar 检验，**29 对里没有一对在 α=0.05 下可分**（arXiv:2609.17394）；同一模型换脚手架的分差可达 **29.8 个百分点**，而前 30 名彼此只差 8.8 个百分点。榜单只能告诉你「同一档」，不能告诉你「谁第一」。 |
| 「用 tiktoken 估成本就够了」 | 各厂商 tokenizer 不同：实测用 cl100k_base 估 Claude 的成本**系统性低估约 41%**（llm-tokens-atlas，n=12,500）；AA 也是「价格按 native token、能力指标按 OpenAI token 标准化」两套口径。 |
| 「便宜模型不能干正事」 | MiMo-V2.6-Flash（¥1/¥2）AA 智能 **37.9**，已能覆盖分类、抽取、改写、简单编码；MiMo-V2.6-Pro（¥3/¥6）**46.3**，进入前沿区间——比 16GB 机器上能跑的本地 9B 模型（AA 约 13）高近 3 倍。 |
| 「榜单分数可以跨榜比」 | 不同 harness、不同工具权限、不同思考预算下的 SWE-bench / Terminal-Bench 分数**不可直接比较**；AA 指数是同一套 harness，才有可比性。 |
| 「促销价就是常态价」 | Gemini 3.8 Flash 的 $0.75/$3.75 到 **2026-12-31** 结束，之后翻倍；签长约必须按 $1.50/$7.50 算。 |
| 「长上下文只是按量多花钱」 | 越过阈值单价就翻倍，而且**可能整单翻倍**：OpenAI 价目表把 >272K 输入单列一档（gpt-6-astra $10/$50 → $20/$75）；xAI 文档明确「prompt 一旦达到 200K 阈值，**该请求的全部 token** 按长上下文价计费」（$2/$6 → $4/$12）。 |

## 相关问题

- **为什么 AA 的「每任务成本」和我账单对不上？** → AA 跑的是它自己的 10 项评测（含长文档、Agent 任务），token 用量结构和你业务不同；它是**横向比较**用的相对指标，不是报价。
- **国内调用和海外调用价差多少？** → 同一模型常有国内外两套价（小米 MiMo 国内 ¥3/¥6 vs 海外 $0.435/$0.87，约合 ¥2.9/¥5.8，接近；Kimi 国内 ¥20/¥100 vs 国际 $3/$15 ≈ ¥20/¥101，也接近）。计费币种和网络链路才是主要区别。
- **本地部署 vs API 怎么算？** → 见 [[2026年10月-M4-16GB-Ollama小模型选型]]。量级对比：M4/16GB 能跑的 `qwen3.5:9b` AA 智能约 **13**，而在线 **MiMo-V2.6-Flash** 是 **37.9**、每百万 token 只要 ¥1/¥2。本地部署买的是隐私、离线和零边际成本，**不是能力**——能力差近 3 倍。
- **API Key、限流、配额怎么与成本挂钩？** → 见 [[API网关鉴权与传输安全]]。

## 技术拓展

### 1. 2026 年的价格趋势

- 中国厂商 2026 年上半年多次下调 API 价格，部分被宣布为**永久降价**（MiniMax-M3 的「永久五折」直接把 ¥4.2/¥16.8 划掉）。
- 头部国际厂商转向**分层计价**：不再单纯降价，而是用 Flex/Batch（半价）→ Standard → Fast（2 倍）→ Ultrafast（6 倍）把同一模型的算力切成不同 SLA 卖。
- 高价档反而在变贵：Fable 5.1 / Mythos 5.1 定在 $10/$50，比上一代 Opus 的 $5/$25 翻倍——**前沿能力正在变成奢侈品**。

### 2. AA 智能指数 v4.3.2 的构成

10 项评测加权：Agents 30%（AA-Briefcase 15%、GDPval-AA 10%、AutomationBench 5%）+ Coding 20%（Terminal-Bench 4.0 10%、SciCode 10%）+ 科学推理 20%（HLE、CritPt）+ 通用 30%（AA-Omniscience 15%、GDP.pdf 10%、AA-LCR 5%）。

值得注意的是权重向 **Agent 任务**倾斜（30%），而且 GDPval-AA 用 Elo 打分，锚点定为 **DeepSeek V4.1 Flash (max) = 1600**——这说明它已经被当作「基准档」模型。

### 3. 评测与选型的坑

- **「分差」大多不是「能力差」**：arXiv:2609.17394 审计 254 份 SWE-bench 提交后发现，Verified 前 30 名的相邻两两配对 McNemar 检验 **0/29 通过**（α=0.05）；同模型只换脚手架的分差可达 **29.8 个百分点**，而前 30 名彼此总分只差 8.8 个百分点。Epoch AI 也记录过「一个模型仅因脚手架不同，从 62.3% 到 70.2%」。
- **自报 vs 第三方复现**：SWE-bench Verified 聚合榜 32 条记录里**只有 3 条是第三方 verified**（榜首 93.9% 的来源是厂商 system card）；Terminal-Bench 37 条里只有 6 条 verified。**厂商 model card 分数只能当上限看**。
- **人类偏好榜要看票数**：LMArena 文本榜（2026-10-02 快照，862 万票）第一是 gemini-4-argon-high（1525 分），但只有 **4,932 票、±9、标 Preliminary**；第二名 claude-opus-4-6-high 是 1505 分 / 77,636 票 / ±3。前 10 里性价比最高的是第 8 名 **gemini-3.8-flash-high（1495 分，$0.75/$3.75）**——把 Preliminary 条目当稳定排名是常见误用。
- **污染检测本身不可靠**：arXiv:2510.02386 指出，即使短暂的 GRPO 训练也能大幅掩盖多数污染检测方法依赖的信号，检测「接近随机猜测」——榜单高分不完全等于真能力。
- **tokenizer 不同 → 成本估算系统性偏差**：实测用 cl100k_base 估 Claude 成本中位低估 **+41.3%**（100% 样本都低估），Google +4.5%、Cohere +3.2%，OpenAI 才是真值。中英混排、代码、JSON 上差异更大；AA 因此把「价格」和「能力指标」分成 native token / OpenAI token 两套口径。
- **一个经典教学案例**：Aider Polyglot 榜单（225 题，页面最新记录停在 2025-08-25，已停更）公开了每轮总成本——`gpt-5 (low)` 81.3% 用 **$10.37**，`o3-pro (high)` 84.9% 用 **$146.32**：高 3.6 个百分点，贵 **14 倍**；同一模型从 low 档升到 high 档，成本涨 2.8 倍只换来 6.7 个百分点。
