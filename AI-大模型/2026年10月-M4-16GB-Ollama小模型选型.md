# 2026 年 10 月：M4 / 16GB 上 Ollama 小模型选型（1B–14B）

## 核心结论

1. 首选 **`qwen3.5:9b`**（6.59GB / 256k ctx）——中文最强、上下文最长，16GB 上仍能全 GPU 驻留。
2. 需要**多模态/音频**再加 **`gemma4:12b`**（8.02GB / 128K），但它和 9B 不要同时常驻。
3. 磁盘 35GB 只够放这 4 个模型中的 ~4 个：全部拉取约 28GB，剩 7GB。

## 一、四个推荐

### 1. `ollama pull qwen3.5:9b` — 日常主力
- Qwen 3.5 系列（多模态 + vision + tools + thinking），尺寸档：0.8b / 2b / 4b / 9b / 27b / 35b / 122b
- 下载 **6.59GB**；运行时约 6.6GB + KV cache。上下文 **256k**
- 擅长：中文、通用问答、tools、长上下文
- 短板：新系列（页面约 7 个月前建、11 小时前更新），第三方横向评测少；9B 推理深度不及 14B 级
- 16GB 速度量级：**25–45 tok/s**（16GB 档 7–8B 基准为 40–80 tok/s，9B 更重）

### 2. `ollama pull gemma4:12b` — 多模态 / 长文
- Gemma 4 12B，dense **encoder-free** 多模态，首款支持**音频输入**的中等尺寸 Gemma；128K ctx
- 下载 **8.02GB**（Q4_K_M 7.38GB + 视觉投影 175MB + draft 465MB）
- 擅长：图文/音频/视频理解、agentic、代码
- 短板：8GB 级，16GB Air 上余量很小；与浏览器/Docker 抢内存；中文一般
- 速度量级：**18–35 tok/s**

### 3. `ollama pull ministral-3:8b` — 轻量补充
- Ministral 3 8B Instruct（2512，2025-12-04 发布），面向 edge 部署；256k ctx
- 下载 **6.02GB**
- 擅长：指令跟随、函数调用、英文
- 短板：页面 9 个月未更新（家族已有 3b/8b/14b）；中文弱于 Qwen
- 速度量级：**30–50 tok/s**

### 4. `ollama pull qwen3:8b` — 实验基线
- Qwen3-8B：8.2B 参数，原生 32,768 ctx，YaRN 可到 131,072；Ollama 标 40K
- 下载 **5.2GB**
- 擅长：可复现的对照基线、thinking 模式、中文
- 短板：已被 3.5 取代，属上一代
- 速度量级：**35–60 tok/s**

## 三、推理性能实验适配度

- **上下文可调 ✅**：`qwen3.5:9b`（256k，最灵活）、`qwen3:8b`、`ministral-3:8b`（256k）
- **不要选**：`gemma4:12b` 在 16GB 上拉长 ctx 会直接爆内存
- **`ollama run --verbose`** 输出 `prompt eval rate` / `eval rate`（tokens/s），实测本机 0.13.2 支持
- **API 耗时字段**（纳秒）：`total_duration`、`load_duration`、`prompt_eval_count`、`prompt_eval_cached_count`、`prompt_eval_duration`、`eval_count`、`eval_duration`
  - TTFT ≈ `load_duration + prompt_eval_duration`（预热后去掉 load）
  - TPOT ≈ `eval_duration / eval_count`
- **`ollama ps`** 显示 `SIZE` / `PROCESSOR` / **`CONTEXT`**（实际分配的 ctx）
- **环境变量**（0.13.2 实测存在）：`OLLAMA_KV_CACHE_TYPE`、`OLLAMA_FLASH_ATTENTION`、`OLLAMA_CONTEXT_LENGTH`、`OLLAMA_NUM_PARALLEL`、`OLLAMA_MAX_LOADED_MODELS`、`OLLAMA_KEEP_ALIVE`、`OLLAMA_DEBUG`
- **坑**：`<24GiB VRAM` 默认 ctx 仅 **4k**，需显式设 `num_ctx`；首轮 TTFT 含 load，要丢弃；prompt 命中缓存后 `prompt_eval_count` 可能为 0

## 四、动手前必须处理的版本问题

**实测复核（2026-10-03）**：`ollama pull` **并非全部被拒**，而是**按模型新旧分**：

| 模型 | 结果 |
|---|---|
| `qwen3:8b`（旧一代） | ✅ 正常下载（5.2 GB） |
| `qwen3.5:9b` / `gemma4:12b`（2026 新一代） | ❌ HTTP **412**：`requires a newer version of Ollama` |

本机 `ollama 0.13.2`，`brew` 可升到 **0.35.0**。

**所以**：
- 只用 qwen3 一代 → **不升级也能开工**
- 要用 2026 新一代 → **必须 `brew upgrade ollama`**
