# my-tech-notes

技术学习笔记。**所有笔记平铺在根目录**，分类靠 frontmatter 标签，导航靠这一页。

## 为什么要平铺

以前是按技术分文件夹（`Java/`、`Go/`、`Others/`），现在取消了，原因：

| 问题 | 说明 |
|---|---|
| **文件夹是单标签** | 一篇笔记只能放一个地方。而《HTTP 框架本质：Gin 与 Kitex》既是 Go 又是架构设计，逼你二选一 |
| **分类维度会打架** | 原来的 `Others/` 里塞着 Git、正则、网络代理、LazyVim、代码规范、Orca 评估——唯一的共同点是"不是 Java 也不是 Go" |
| **会持续膨胀** | 以后学 Rust、K8s、AI Infra…… 每加一个就要开文件夹并纠结归属 |
| **和 Obsidian 重复** | Obsidian 原生的分类工具是**标签**（标签面板、`tag:#大模型` 搜索、图谱视图、双链），都比文件夹强 |

**组织方式改为三层：**

- **标签**（frontmatter `tags`）→ 一篇笔记可以属于多个领域
- **本页索引** → 人工维护的导航，随时可调，不产生目录结构
- **双链**（`[[笔记名]]`）→ 笔记之间的关联

新增笔记只需要三步：平铺到根目录 → 写 frontmatter 标签 → 在下面加一行链接。

## 笔记格式

元信息写在 frontmatter（Obsidian 属性能识别；正文里写"标签：xxx"识别不了）：

```markdown
---
date: YYYY-MM-DD
tags: [标签1, 标签2]
---

# 标题

## 问题
## 回答
### 核心结论
### …
## 常见误解
## 相关问题
## 技术拓展
```

**复习时只看两处**：开头的「核心结论」和末尾的「常见误解」。

标签不能含空格，多个词用连字符：`KV-Cache`、`AI-Infra`。

详细规则见 [AGENTS.md](AGENTS.md) / [CLAUDE.md](CLAUDE.md)。
