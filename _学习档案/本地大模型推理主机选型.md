# 本地大模型推理主机选型（游戏为主 + vLLM 实验）

## 问题

大四学生，现有 M4/16GB Mac，想配一台 1 万多元的 Windows 整机：主要打游戏，顺带跑 7B-Q4 推理测 TTFT/TPOT、观察 KV cache，跑 vLLM（需要 NVIDIA + Linux）。该选什么显卡和配置？

## 核心结论

1. **这个场景里显存容量 > 算力**：decode 阶段是 memory-bound，且 KV cache 随上下文线性吃掉显存，OOM 了算力再高也是 0。
2. **2026 年 10 月正在经历 AI 引发的存储/显卡涨价潮**，1 万多元整机基本只能落在 RTX 5070 ~ 5070 Ti 16GB 档；想要 24GB 显存，只有二手 3090 或加预算到 2 万+。
3. WSL2 跑 vLLM 学习够用，压测/多卡才需要双系统。

## 回答

### 1. 显存需求（权重按 Q4_K_M 估）

| 模型 | 权重 | +KV cache/开销后实际需要 |
|---|---|---|
| 7B-Q4 | ~4.5GB | 8GB 勉强，12GB 舒适，32K 上下文建议 ≥16GB |
| 13B-Q4 | ~8GB | 12GB 紧张，16GB 舒适 |
| 70B-Q4 | ~40GB | 单卡消费级跑不动，需 2×24GB 或 CPU offload |

KV cache 公式：`2 × 层数 × KV头数 × head_dim × 精度字节 × token 数`。8B 级模型 FP16 约 128KB/token，32K 上下文 ≈ 4GB——和权重一个量级。**容量决定"能不能跑、开多大上下文、多少并发"（vLLM 的 `gpu_memory_utilization` 要先切一大块给 KV pool），算力只决定"多快"。** 游戏则相反，吃算力和带宽，所以两者不冲突。

### 3. 整机配套

| 部件 | 建议 |
|---|---|
| CPU | R7 9700X / 9800X3D 或 i5-14600K 级，游戏够且不抢显卡预算 |
| 内存 | 32GB DDR5-6000（[套装已涨到 ~3100 元](https://news.17173.com/content/09232026/200353719.shtml)），AI 实验想 64GB 要额外加钱 |
| 电源 | 5070 Ti → 750W 金牌；3090/5090 → 850W–1000W |
| 主板 | B650/B850（或 B760）；双卡必须支持 x8/x8 拆分 |
| 存储 | 1TB PCIe 4.0 NVMe（比型号速度更重要：7B-Q4 才 4.5GB，70B-Q4 40GB） |

预算提醒：GPU 会吃掉整机 60%+；涨价潮下"1 万多元"约等于 5070 Ti 整机，24GB 显存方案请按 1.5 万–2 万规划。

### 4. Windows 上跑 vLLM

**能用但只算"学习级"**：WSL2 支持 CUDA 直通，vLLM 可在其中运行，适合验证 PagedAttention / continuous batching / 测 TTFT。已知坑：显存只涨不缩（回收差）、旧版 WSL 在 Blackwell（sm_120）上 CUDA graph capture 异常（[WSL 2.7.0 已修](https://github.com/microsoft/WSL/issues/14452)、[睡眠模式受限](https://discuss.vllm.ai/t/window10-wsl2-vllm/2735)）、pin memory/NCCL 多卡基本不可用、Triton/FlashAttention 编译依赖要装全套 CUDA toolkit，性能比裸机有损失。

双系统（或加块小 SSD 装 Ubuntu）更接近生产、多卡/压测友好，代价是要重启切换。**建议：WSL2 起步，认真做性能实验时再上双系统。**

## 关键提醒（常见误解）

- **魔改卡 / 矿卡**：市面已有 5090 魔改 96GB（[$5600 起](https://en.gamegpu.com/news/zhelezo/neobychnaya-versiya-rtx-5090-s-96-gb-gddr6-pamyati-prodaetsya-v-kitae-ot-usd5600)），显存是焊改的，驱动、稳定性、保修全无保障；3090 普遍有矿史，优先京东自营二手或有质保渠道，别碰无保涡轮卡。
- **16GB vs 24GB**：16GB 能覆盖 7B-Q4 长上下文和 13B-Q4；24GB 才舒服，但**70B 依然跑不了**，别为"以后跑 70B"多花钱。
- **消费级多卡可行但性价比低**：GeForce 无 NVLink，靠 PCIe TP=2 各持 24GB；要双 x8 主板、大电源、大机箱，且 WSL2 下多卡支持差。预算内不如单卡 + 租云。
- **数据可信度**：本次 `web_fetch` 被沙箱阻断（域名解析失败），价格全部来自 2026-10-01 的搜索结果标题/摘要，未逐页核实原价；涨价潮下价格波动极快，下单前请以当日京东/淘宝实价为准。文中"4090 二手价"两条来源互相矛盾，已标注待核实。

## 相关问题

- 为什么 7B-Q4 在 12GB 卡上跑长上下文会 OOM → KV cache 线性增长且 vLLM 默认预留约 90% 显存给权重+KV，上下文越长 KV pool 越大。
- TTFT / TPOT 分别受什么影响 → TTFT 由 prefill 算力决定，TPOT 由显存带宽和 batch 决定（参见 [[推理性能与显存]]、[[KV-Cache原理]]）。
- 要不要为了 AI 买 Mac Studio 大内存 → 统一内存能装大模型但 vLLM/CUDA 生态不适用，本场景仍选 NVIDIA。
