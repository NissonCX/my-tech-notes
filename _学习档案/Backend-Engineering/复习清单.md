# Backend Engineering 复习清单

> 最近一次学习复述：2026-10-31　｜　下次建议复核：2026-11-02

## 核心结论

1. 复杂度来自业务不变量、并发和失败恢复，不来自中间件数量。
2. 首版采用租户感知的数据模型，只启用一个种子租户。
3. 首版不使用 Kafka；v2 在出现可靠异步副作用后使用 Outbox + Kafka。
4. ES 只承担搜索召回，MySQL 仍是事实源。
5. 不可逆决定早做，可替换基础设施等明确触发条件满足后再加。
